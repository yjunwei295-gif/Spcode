# 视觉说明

当主模型不支持看图时，SimpleCode 会按「文件 → 模型组合」中当前主模型挂上的看图槽位自动处理图片：

1. 优先用本地 GGUF 看图模型（需 mmproj 投影文件），由内置引擎在本地加载识别，识别结果以文字注入对话，主模型继续原任务。
2. 若槽位填了本机 OpenAI 兼容端点（LM Studio / llama.cpp server），本地识别失败时会降级到该端点。
3. 都不可用时给出明确提示，**绝不伪造识别内容**。
4. 全程不调用任何外部云端服务，图片数据不离开本机。
