## SimpleCode 1.0.0

Windows x64 安装包（NSIS，约 427 MB，内含 Electron 运行时，无需另装 Node.js）。

### 本次更新
- 新增思考轮次预算：每轮注入「已用 / 上限 / 剩余」，剩余不足时催收敛，禁止向用户索要轮次；上限由用户设置在「模型组合」里决定
- 联网口径写进提示词：明确本程序可联网检索、可能注入搜索结果，禁止编造「不能联网」这类能力限制
- 新增链路日志定因闸门：根因不明时先写【链路日志探针】、只派只加日志的单；正文出现【确定能修】后用户再说「开始」才允许派业务修复。探针阶段程序会硬拦非日志派单
- 新增 zabingAI 本地模型槽，指向本机 qwen2.5-coder-7b-instruct q4_k_m 权重
- 联网检索触发词补充：「查一下 / 查一查 / 找一下 / 公开信息 / 私服」等外网事实类问题也会自动检索
- 大文件快照差异改为按改动块对齐，避免只展示文件开头；总结会展开更多差异块，减少漏报后续改动

### 安装
下载后双击安装，可选安装目录；安装完会在桌面和开始菜单建 SimpleCode 快捷方式。

> 模型权重不随安装包分发，请自行放入 `.gguf` 文件。
