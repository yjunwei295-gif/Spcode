## SimpleCode 1.0.2

Windows x64 安装包，内含 Electron 运行时，无需另装 Node.js。

### 本次更新
- 桌宠增加常驻工作图标和短标签，区分读文件、查代码、改文件、构建、验证、等待确认等真实工作状态。
- 保留猫娘皮肤和详细气泡，工作类别短标签与详细正文分开显示。
- 主窗及桌宠支持带图插话，附件沿用实际会话传递。
- 增加代码作品预览、导出、音频合成与采样分析入口。
- 更新 Claude Code 接入、模型处理及首次启动引导。

### 已知限制
- 桌宠在最小缩放下显示长正文时，详细气泡与角色可能重叠，现有输入布局回归未通过。
- 本版不包含先前汇报中的自设输入唤起键接口。

### 安装更新
完全退出旧程序后运行安装包，安装到原目录。保留 `%APPDATA%\SimpleCode` 中的设置和会话；模型权重不随安装包分发。
