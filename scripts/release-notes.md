## SimpleCode 1.0.0

Windows x64 安装包（NSIS，约 427 MB，内含 Electron 运行时，无需另装 Node.js）。

### 本次更新
- AGI 收工自动汇报：AGI 开着时每轮结束都会汇报本轮做了什么（看了哪些屏、点了什么、跑了什么命令、改了哪些文件），不再只在改了文件时才出总结
- 迁移旧配置时清空 API Key：从旧版本升级时，settings.json 里的 apiKey / api_key 一律置空，只搬运会话、快照与日志
- 修复命令沙盒 start 收尾：点「停止」立即结束命令，不再一直卡在执行中
- 修复无边框窗口拖动区覆盖过大：输入框、按钮在安装包里可正常点击与聚焦
- 总结生成正文为空时回退读取思考内容，避免进度会话保存空总结
- AGI 模式全解放：AGI 打开时不再等「开始」，放开写文件与命令工具
- 修复 xlsx 依赖版本、更新 README 版本与仓库地址

### 安装
下载后双击安装，可选安装目录；安装完会在桌面和开始菜单建 SimpleCode 快捷方式。

> 模型权重不随安装包分发，请自行放入 `.gguf` 文件。
