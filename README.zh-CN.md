# SimpleCode / SpCode

**能直接读改项目文件、运行构建与测试、组合在线或本地模型，并能操作 Windows 桌面软件的 AI 编程助手。**

[English](README.md) | [简体中文](README.zh-CN.md) · [下载 Windows 安装包](https://github.com/yjunwei295-gif/Spcode/releases/latest) · [中文逐步操作手册](docs/user-guide.zh-CN.md) · [Detailed English user guide](docs/user-guide.en.md)

当前版本：**1.0.4，Windows 10/11 x64**。安装包包含应用运行时，普通用户无需安装 Node.js；模型账号、API 额度、本地模型权重需要另行配置。

## 这个软件到底是做什么的？

SimpleCode 把聊天窗口与电脑上的项目目录连接起来。你说清需求后，助手可以读取代码、定位实现、修改文件、执行项目命令，再汇报改动和验证结果。你不必把它给出的每段代码手工复制到编辑器里。

它适合这些工作：

- **看懂旧项目**：打开代码目录，询问功能入口、模块职责、调用链，以及修改某个方法会影响哪里。
- **改功能、查 Bug**：描述现象与预期，让助手先找原因、提出范围，再实际修改并执行相关验证。
- **统一使用不同模型**：在同一界面配置在线 API、支持的 Codex/Cursor/Claude Code 接入，或者直接运行兼容的本地 GGUF。
- **按工作分配模型**：主模型负责理解任务，规划、代码、总结、看图和媒体生成可以分别配置模型。
- **操作可视化软件**：开启测试版 AGI 后，助手可读屏、点击、拖动和输入，协助处理 Windows 应用中的操作。
- **制作可预览作品**：用代码制作流程图、网页演示、交互图表或动画，打开独立预览，再导出支持的格式；生成图片则使用另行配置的生图模型。
- **离开主窗口也能看进度**：桌宠显示工作状态和当前大脑所属厂商的额度，点开后可以继续聊天。

例如，打开一个游戏项目后，你可以说：“场景开始时镜头会跳一下，先找出调用链和原因，暂时不要改文件。”看懂原因后再授权实现，并要求运行构建或给出能复现的行为验证。

## 从需求到结果，会发生什么？

1. **你选择项目目录。** 文件操作和项目命令围绕这个工作区执行；需要时可明确添加附加目录。
2. **你选择模型。** 请求发往已配置厂商或本地运行时。安装软件并不等于获得所有模型的付费访问权。
3. **你说明目标与约束。** 可以添加附件、用 `@` 引用代码、用 `/` 选择技能。
4. **助手调用 SpCode 工具。** 读文件、搜索、编辑、命令或桌面动作显示为任务活动。普通模式可走“核对方案再开始”；AGI 面向直接执行。
5. **你核对证据。** 文件写入仅代表源码保存；构建通过代表相应编译检查通过；行为测试只能证明它实际覆盖的行为。
6. **你审阅结果。** 利用改动文件、快照、历史与里程碑检查工作；需要恢复时由你在界面操作。

## 1.0.4 新增内容

- **长时存活**：保存长期目标与允许范围，设置检查间隔和单轮超时，启停定时任务，查看内存与持久化进度；目标和上下文复用现有导图。
- **有界自动上下文**：JSONL 分页归档保留完整结果，历史选择最多 20 轮，预览和续做进度最多末尾 6000 字；不消费手动草稿，普通聊天保留。
- **厂商改进**：Cursor 账号/套餐诊断与重新登录处理；MXAPI OpenAI 兼容及原生 Nano 异步生图入口。
- **完整双语说明**：两份介绍与各 21 章手册，覆盖配置、入口、流程、依赖和当前限制。

定时任务需要软件运行、电脑不休眠、目标标签活动且其他任务空闲；退出后没有后台服务。超时和中断会暂停，本次未连续数天运行，也未实际发布社交平台内容。

## 下载并安装 Windows 版

1. 打开 [Releases](https://github.com/yjunwei295-gif/Spcode/releases/latest)。
2. 如果附件折叠，展开 **Assets**。
3. 下载 **`SimpleCode-Setup-1.0.4.exe`**；“Source code”压缩包是源码，不是安装程序。
4. 更新前完整退出旧程序，包括仍在运行的桌宠实例。
5. 运行安装程序，按向导选择安装位置；更新时使用原安装目录。
6. 从快捷方式启动 **SimpleCode**。
7. 右上角可切换 **中文 / EN**。部分新面板仍保留中文，英文手册已注明对应原文。
8. 配好模型后，再发送项目任务。

安装包约 662 MiB，不包含模型权重。1.0.4 安装包 SHA256：

```text
bd503a1b18488fd7b735a5802ab8b7d7d039c5884d0b96a9293de28e443faf3f
```

首次安装的每一步及预期画面见[安装与首次启动](docs/user-guide.zh-CN.md#s2)。

## 第一次成功使用

1. 打开 **文件 → 设置**。
2. 在 **模型厂商** 中选提供商模板，或创建自定义厂商。按厂商文档匹配协议、接口地址，并填写需要的 API Key。
3. 点击 **测试连接**，再点 **添加**。
4. 在 **模型列表** 里选刚才的厂商，点击 **拉取模型列表**。
5. 勾选需要的模型，把它加入已保存模型；点击 **使用**，再点 **完成**。
6. 如果首次引导要求配置模块，给 **总结、代码、规划** 三项选择默认模型，再完成引导。三个角色可以使用同一个已保存模型，不要求购买三个账号。
7. 点击 **文件 → 打开项目**，选项目根目录。
8. 在输入区上方的模型菜单确认当前模型。
9. 发送：“只读梳理这个项目如何启动，列出入口文件和主要调用链，先不要改任何文件。”
10. 核对回复和工具活动。读项目流程跑通后，再试一个范围明确的小改动。

使用本地模型或 SDK 登录时，按[完整操作手册](docs/user-guide.zh-CN.md#s4)中对应分支配置。

## 数据、费用与当前边界

- 设置、会话和日志通常位于 `%APPDATA%\SimpleCode`；安装版默认模型目录在其中，也可另选位置。
- 使用在线模型时，任务所需内容和上下文会进入对应模型请求；桌面任务可能包含屏幕信息。混合本地与在线模型的工作流不等于全程离线。
- 下载模型和首次准备运行时需要网络。能否运行本地模型取决于兼容性和实际内存/显存。
- API 费用、订阅限制、可用模型和额度由厂商决定。手动余额是本地估算账本，不是厂商账单。
- AGI 为测试功能，使用真实鼠标键盘；在同一桌面同时手工操作，可能互相影响。
- 切到 EN 后，部分新界面、默认技能和人设仍有中文；可在应用内定制。
- 图片、视频和 3D 生成需要相应后端及模型；普通聊天模型不会自动拥有全部生成能力。
- 语音输入尚非完整语音识别流程；SSH 入口目前是本地映射目录/连接检查，不是完整远程 IDE。
- 本次发布验证的是 Windows x64；没有提供 macOS/Linux 安装包。

具体目录和分享数据时的注意点见[数据与隐私](docs/user-guide.zh-CN.md#s17)。

## 从源码启动

使用当前 Node.js LTS（推荐 Node.js 24）、npm 和 Git。本地推理依赖要求 Node.js 至少 20；这与安装版自带运行时是两回事。

```cmd
git clone https://github.com/yjunwei295-gif/Spcode.git
cd Spcode
npm install
npm start
```

构建 Windows 安装包和便携程序：

```cmd
npm run dist:win
```

打包后验证真实应用：

```cmd
node scripts/verify-release.cjs
```

完整开发步骤见[开发与验证](docs/user-guide.zh-CN.md#s20)，已执行和跳过的检查见 [1.0.4 核对记录](docs/release-1.0.4-verification.md)。
