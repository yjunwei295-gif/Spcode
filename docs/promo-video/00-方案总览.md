## 1. 一句话定位（片头、简介、置顶评论都用它）

> **SpCode：Windows 上开源的桌面 AI 编程助手。接在线模型、跑本地 GGUF、按任务组合多模型、看图不外发，还能自己看屏幕动手。**

## 2. 目标受众（决定了每一段该说什么）

1. **正在用 Cursor / Claude Code / Cline / Copilot 的开发者** —— 他们对"AI 改代码"已经有概念，要打的是差异化：模型自选、看图不外发、免费。
2. **关注隐私与成本的人** —— 代码和截图不想上云，也不想每月付订阅。
3. **本地模型玩家** —— 手里已经有一堆 `.gguf`，缺一个能直接挂上去干活的壳。
4. **国内开发者** —— 中文原生界面、找模型要能连 HuggingFace / 走镜像。

## 3. 差异化对比（视频里做逐行出现的对比表）

| 能力 | SpCode | Cursor | Claude Code | Cline / Copilot |
| --- | --- | --- | --- | --- |
| 开源 | 全开源（Electron 源码） | 闭源 | 闭源 | 部分开源 / 闭源 |
| 本地 GGUF 直接运行 | 内置 `node-llama-cpp`，不用另架服务 | 不支持 | 不支持 | 插件依赖外部服务 |
| 内置模型下载器 | 按用途 + 本机配置推荐、多线程、断点续传 | 无 | 无 | 无 |
| 主模型挂辅助槽位 | 看图 / 总结 / 代码 / 规划 四个槽 | 模型固定 | 模型固定 | 单模型 |
| 看图不外发 | 本地视觉先转文字，再喂主模型 | 原图上传云端 | 原图上传云端 | 原图上传云端 |
| 改文件自动快照 | 有，可一键还原 | 部分 | 无 | 部分 |
| 技能 / 规则 / 人设 | `/技能` 调用，项目级 `.simple/` | 仅规则文件 | 部分 | 部分 |
| 看屏幕 + 键鼠动手 | 有（AGI 模式） | 无 | 无 | 无 |
| 价格 | 软件免费；模型可选本地 0 成本 | 约 20 美元/月 | 按 API 计费 | 混合计费 |
| 中文原生 | 界面 + 文档 + 技能全中文 | 一般 | 一般 | 一般 |

## 7. 执行顺序（照这个顺序做，不返工）

```
录制屏幕素材 ---> 生成视觉素材(封面/章节卡/对比表) ---> 必剪粗剪 ---> 配音 ---> 字幕 ---> BGM与音效 ---> 精剪对齐 ---> 导出 ---> 发布
```

录屏一次录长一点（每段比正片多留 3–5 秒余量），剪辑时再切，比反复录省事。

## 8. 全片统一参数

| 项 | 值 |
| --- | --- |
| 录制 / 成片分辨率 | 1920×1080 |
| 帧率 | 60 fps（录屏字体滚动更顺）；竖屏切片 30 fps |
| 录制码率 | 8–12 Mbps，CBR |
| 导出码率 | 12 Mbps，H.264，AAC 192 kbps |
| 系统缩放 | 录制前把 Windows 显示缩放设成 100%，避免界面发虚 |
| 界面主题 | 用 SpCode 浅色主题（电路板），录屏干净，筛选项少 |
| 字幕 | 思源黑体 / 微软雅黑，白色描边，字号 48（1080p），底部安全区 |
| BGM 音量 | 约 -22 dB（人声 -6 dB），解说出现时自动闪避 |
