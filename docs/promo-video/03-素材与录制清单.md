# 素材与录制清单（可直接照做）

## 一、录屏环境准备

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 启动 OBS（Steam 版），路径：`C:\Program Files (x86)\Steam\steamapps\common\OBS Studio\bin\64bit\obs64.exe` | Steam 版和官网版功能一致 |
| 2 | 首次启动会弹「自动配置向导」→ 选 **仅为录制优化** → 下一步 → 应用设置 | 分辨率 1920×1080 |
| 3 | 添加来源 → **显示器采集** → 选主显示器 | 一个显示器就够，不要加摄像头 |
| 4 | 设置 → 输出 → 输出模式改 **高级** → 录像：编码器 `x264` 或 `NVENC H.264`，码率 `10000 Kbps`，CBR，关键帧 2s，预设 `veryfast`（NVENC 用 `P5`） | 文字多的画面码率给足 |
| 5 | 设置 → 输出 → 录像格式 `mp4`（或 mkv，更抗崩溃，剪辑前再转） | mkv 崩溃不掉文件 |
| 6 | 设置 → 视频：基础分辨率 = 输出分辨率 = `1920×1080`，帧率 `60` | 输出分辨率和基础一致，字才清晰 |
| 7 | 设置 → 快捷键：给「开始录制」「停止录制」各绑一个（默认 `Ctrl+F9` 无效的话手动绑） | 录的时候不用切窗口 |
| 8 | 设置 → 高级 → 录像路径改到 `D:\SpCode-push\docs\promo-video\raw\` | 素材集中放，剪辑时好找 |

**录制前先关掉的东西**：微信 / QQ 弹窗提醒、Steam 好友通知、杀毒软件弹窗、桌面图标、任务栏无关图标（右键任务栏 → 隐藏）。

**系统设置**：显示缩放改 100%；SpCode 用浅色主题；窗口最大化，不要半屏。

## 三、录屏脚本（照顺序录，每段一次过）

录的时候按 `f9`（或绑的快捷键）开始/停止，停完立刻在心里过一遍：画面有没有弹窗、鼠标有没有乱飘。

| 顺序 | 文件命名 | 时长 | 操作流程 |
| --- | --- | --- | --- |
| 1 | `REC-01-主界面.mp4` | 15s | 启动 SpCode → 文件 → 打开项目 → 选 `D:\SpCode-push` → 鼠标慢速划过左上文件树 → 停在对话区 3 秒 |
| 2 | `REC-02-在线模型.mp4` | 15s | 文件 → 设置 → API 模型 → 新增 → Base URL / Key / 模型 ID 逐个填入（Key 用 `sk-demo-xxxxxxxx`）→ 点测试连接 |
| 3 | `REC-03-本地模型.mp4` | 12s | 设置 → 本地模型 → 停在「模型目录」路径上 → 用资源管理器打开该目录 → 展示 `.gguf` 文件 |
| 4 | `REC-04-下载模型.mp4` | 25s | 设置 → 下载模型 → 选「写代码」→ 选一条推荐 → 下载 → 进度走 5 秒 → 暂停 → 继续（演示断点续传） |
| 5 | `REC-05-模型组合.mp4` | 20s | 文件 → 模型组合 → 展开主模型的四个槽（看图 / 总结 / 代码 / 规划）→ 鼠标逐个划过 |
| 6 | `REC-06-看图流程.mp4` | 30s | 对话里粘贴一张图 → 等本地视觉输出识别文字 → 主模型基于文字回答；这一段把界面放大到 110% 更方便看 |
| 7 | `REC-07-快照还原.mp4` | 25s | 让助手改一个小文件（如 README 里加一行）→ 右侧「已更改 1 个文件」→ 点还原 → 内容变回 |
| 8 | `REC-08-技能调用.mp4` | 15s | 输入框打 `/` → 技能列表弹出 → 选一个 → 回车 → 助手按技能执行 |
| 9 | `REC-09-项目规则.mp4` | 12s | 资源管理器展开 `D:\SpCode-push\.simple\`（或 `skills/`、`rules/`）→ 展示规则文件内容 |
| 10 | `REC-10-AGI操作.mp4` | 30s | 打开 AGI → 让它做一个短操作（例如打开记事本输入一行字）→ 屏幕出现识别高亮 → 自动点击输入；一镜到底 |
| 11 | `REC-11-切模型.mp4` | 10s | 顶栏模型下拉 → 在 API 模型和本地模型之间切换两次 |
| 12 | `REC-12-多窗口.mp4` | 10s | 开第二个窗口 → 展示对话分叉与历史列表 |

## 六、旁白录制

- 麦克风距离嘴 15–20 cm，房间关窗关风扇，录之前试录 5 秒听底噪。
- 按 `01-旁白文案.md` 一段一个文件，命名 `VO-01-钩子.wav`。
- 没有好麦克风时：用系统「录音机」+ 手机耳机麦，或先用必剪的「文本朗读」做 AI 配音（选沉稳男声），后期想换真人再替换音轨。
- 录完必做一步：**降噪 + 响度统一**，必剪音频面板里有「降噪」和「音量」预设。
