# 必剪剪辑步骤（逐步照做）

> 目标成片：`1920×1080 / 60fps / 2:40`，另出 `1080×1920 / 30fps / 0:58` 竖屏切片。

## 一、建工程

1. 打开必剪 → 首页点 **开始创作**。
2. 右上角先设 **比例 16:9**、**分辨率 1080P**。
3. 顶部菜单 **文件 → 保存草稿**，命名 `SpCode推广片`，先存一次，之后自动保存。

## 二、导入与铺素材

1. 左上 **本地素材 → 导入素材** → 选 `docs/promo-video/raw/` 里的 12 段录屏 + `assets/` 里的生成图 + `audio/` 里的旁白和 BGM，一次性全导进来。
2. 按 `02-分镜脚本.md` 的镜号顺序，把素材拖到主轨道：
   - 先铺**画面轨**（录屏 + 字卡底图）
   - 再铺**文字轨**（字幕）
   - 再铺**音频轨**（旁白在下、BGM 在最下面）
3. 铺完先不精修，整体看一遍时长够不够 2:40。

## 三、剪画面

1. **切点**：录屏段落的头尾各切掉多余的半秒（`Ctrl+B` 分割，`Delete` 删除选段）。
2. **加速**：等待加载、进度条走动的段落，用「变速 → 常规变速」调到 `1.5x–2x`，音轨不跟随。
3. **放大强调**：需要突出的区域（如「已更改 1 个文件」「识别出的文字」）用「画面 → 裁剪/缩放」，把该区域放大到画面 60% 并居中，配合 0.3 秒缩放动画。
4. **转场**：只在段落之间用，全片不超过 6 处，用「叠化 0.2s」或「白闪 0.15s」，别用花哨的。

## 四、加文字

1. 点 **文本 → 新建文本**，输入字幕内容（照 `01-旁白文案.md` 第二节的字幕表）。
2. 字体选 **思源黑体 CN Bold**；标题 72–90 号，正文 44–48 号；白色 + 2px 黑色描边（保证任何底色都看得清）。
3. 位置：主片底部安全区（距底边 120px）；竖屏切片放画面中上部。
4. 每建立一条样式后点 **保存预设**，后面直接套用，云剪照样式统一。
5. 片头两条主字幕（S01、S02）用「文本动画 → 打字机」或「入场 → 缩放」。

## 五、配音与音乐

1. 旁白：`audio/VO-*.wav` 拖到音频轨，按时间码剪齐；每段之间留 0.3 秒呼吸。
   - 没有真人录音时：文本 → 输入旁白 → **文本朗读** 选沉稳男声 → 生成后拖到音频轨。
2. BGM：拖到最底轨道，音量拉到 **-22 dB 左右**（人声约 -6 dB），开启 **闪避 / 自动压低**（有人声时自动降 8–10 dB）。
3. 音效：在 `01` 里的音效点（片头叮、转场 whoosh、进度叮、还原音）各放一个音效，音量 -15 dB 左右，**不要**每切一次都加。
4. 收尾 2 秒让 BGM 淡出，避免突兀断掉。

## 六、对比表那一段（S21）怎么做

1. 底图用 `G05-对比表底.png`。
2. 用文本图层画表头五列：`能力 / SpCode / Cursor / Claude Code / Cline·Copilot`。
3. 五行内容逐行出现：每列一条文本，入场动画设「擦除 0.2s」，时间上每 0.25 秒出来一行。
4. SpCode 那一列文字用绿色 `#0e9f67`，其余列灰色 `#5d6a66`。
5. 关键两行（本地模型、看图不外发）出现时加一次轻微缩放（100% → 104% → 100%）。

## 七、导出

### 主片

| 项 | 值 |
| --- | --- |
| 分辨率 | 1920×1080 |
| 帧率 | 60 |
| 格式 | MP4（H.264） |
| 码率 | 自定义 12000 Kbps（或选「高画质」） |
| 音频 | AAC 192 kbps |
| 文件名 | `SpCode-推广片-1080p60.mp4` |

### 竖屏切片

1. 复制一份工程：**文件 → 另存为** `SpCode竖屏`。
2. 比例改 **9:16**，把画面重新摆位（录屏段裁成中间区域或缩放到上部 60%，文字放中上）。
3. 按 `01-旁白文案.md` 第三节的 6 句重组，成片 58 秒。
4. 导出 1080×1920 / 30fps / 12 Mbps。

## 八、导出后自检清单

- [ ] 全片信息密度：每 15 秒有至少一个"看得见的功能"
- [ ] 字幕无错别字、无乱码、不超出安全区
- [ ] 没有露出 API Key、本机用户名、私人聊天内容
- [ ] 录屏里没有出现别人的窗口标题、QQ/微信消息
- [ ] 音频整体响度一致，没有忽大忽小
- [ ] 片尾 GitHub 地址能看清、停留 ≥3 秒
- [ ] 竖屏版文字不被平台 UI 挡住（顶部 15%、底部 25% 留空）
