## 二、要先录的屏幕素材（REC 清单）

| 编号 | 时长 | 录什么 | 怎么录（操作步骤） | 用途镜 |
| --- | --- | --- | --- | --- |
| REC-01 | 15s | 主界面全景 | 打开 SpCode → 文件 → 打开项目（选 D:\SpCode-push）→ 打开对话 → 鼠标从左到右缓慢划过左上文件树 → 停 3 秒 | S06/S07 |
| REC-02 | 15s | 在线模型设置 | 文件 → 设置 → 「API 模型」→ 新增一条 → 依次填入 Base URL、Key、模型 ID（Key 用假值）→ 点测试连接 | S08 |
| REC-03 | 12s | 本地模型目录 | 设置 → 「本地模型」→ 显示模型目录路径 → 资源管理器打开该目录，展示若干 `.gguf` | S09 |
| REC-04 | 25s | 下载模型 | 设置 → 「下载模型」→ 选「写代码」→ 选一个推荐项 → 点下载 → 让进度条走 5 秒 → 暂停再继续（演示断点续传） | S10/S11 |
| REC-05 | 20s | 模型组合 | 文件 → 模型组合 → 给当前主模型挂「看图」「总结」「代码」「规划」四槽 → 鼠标逐个划过每槽 | S12 |
| REC-06 | 30s | 看图流程 | 在对话里贴一张本地截图 → 等本地视觉把图认成文字（放大显示那段文字）→ 主模型基于文字回答 | S13/S14 |
| REC-07 | 25s | 改文件 + 快照还原 | 让助手改一个小文件 → 右侧出现「已更改 1 个文件」→ 停止后点还原 → 文件内容变回 | S15/S16 |
| REC-08 | 15s | 技能调用 | 输入框打 `/` → 技能列表弹出 → 选 `zabingsk` → 回车 → 助手按技能回答 | S17 |
| REC-09 | 12s | 项目级规则 | 资源管理器展开 `D:\SpCode-push\.simple\`（若无则用 `skills/`、`rules/`）→ 展示规则文件 | S18 |
| REC-10 | 30s | AGI 操作 | 对话里让它「打开计算器并按 7+8=」或类似小操作 → 画面出现屏幕识别标注 → 它自己点按钮（这一段尽量一镜到底，不要剪碎） | S19/S20 |
| REC-11 | 10s | 顶栏切模型 | 顶栏点模型下拉 → 在 API 模型和本地模型之间切换 | 备用 / 竖屏版 |
| REC-12 | 10s | 多窗口 / 对话分叉 | 开第二个窗口 → 展示对话分叉与历史列表 | 备用 |

小提示：

- REC-06、REC-10 这两段最费时，建议先把本地视觉引擎跑热（第一次启动要下载，会卡），正式录的时候就不会等太久。
- 录屏前把窗口尺寸固定在 1600×900 或 1920×1080（不要半屏），否则成片里黑边多。
