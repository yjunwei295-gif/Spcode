# 长时存活第一版

## 使用与范围

在输入区下方点击「长时存活」，填写长期目标、允许执行范围、检查间隔和单轮超时，再点「保存并开启」。每次检查都会调用当前会话选用的模型；桌面操作仍由 AGI 开关控制。

本版在 SpCode 运行、电脑未休眠、目标会话处于当前标签且没有其它任务执行时调度。忙碌时仅延后检查，不积压任务。切换会话会暂停原任务；关闭窗口、页面重载或渲染进程退出会取消调度与在途执行。软件退出后不运行后台服务。

本版提供长期任务执行基础，不内置某个平台的运营策略、账号或发布接口；也未实际发布视频或评论。

## 导图

「任务目标导图」复用 PlanMap 的绘制、缩放、节点详情和状态刷新，展示完整目标、最近进度和调度信息。该视图不提供源码方案的删除操作。

「上下文记录导图」复用 DialogMap，按页读取磁盘归档。勾选后点击「应用」，后续自动轮次按选择构造历史；取消勾选不删除归档。每页 20 轮，最多选用 20 轮；长回复预览与自动续做进度最多保留末尾 6000 字，完整结果留在磁盘。新完成的轮次自动成为最近进度，历史手动选择仍保留。

自动轮次不消费手动输入的草稿、附件、引用或提示词覆盖，也不更新手动会话的工作记忆。普通聊天保留；自动聊天界面仅保留最近一轮，旧轮次从归档导图查看。

## 状态、停止与异常

检查间隔从上一轮结束时起算；重复开启不会增加定时器，运行中不能重启同一任务。停止后旧回执不能再次调用模型。单轮超时、执行失败及未完成任务的异常退出会暂停，避免自动重做结果不确定的外部操作。取消请求不能撤销已经成功的发布；遇到中断需要核对平台实际结果。

目标、参数、进度及上下文选择保存在用户数据目录 long-alive 的小状态文件中；每轮结果、消息和内存数据追加到同名 JSONL 日志。目录不写死绝对路径。恢复异常中断任务前会明确提示核对结果。

## 内存验证与限制

调度器仅持有一个计时等待或一个在途轮次及其超时计时器。窗口释放时清除定时器和主进程持有的窗口引用。归档采用流式分页；界面只保留最近自动轮，导图关闭释放画布观察器与事件监听。

面板点击「刷新状态」采样主进程 RSS、堆、外部内存及 Electron 进程；每轮日志含 Electron 子进程内存详情。不会在内存里无限累计采样。外部 Edge、独立生成工具等非 Electron 进程不在该列表内。

已完成专项：1000 次启停、150 轮调度、60 轮真实发送函数的受控执行；真实 Electron/preload/IPC 定时触发、停止、导图筛选持久化，以及两种导图各 600 次开关和五批回收后堆采样。模型与平台发送在验收中受控，不消耗真实模型额度。

在工作区内极端同步连续替换状态文件时曾出现一次 Windows EPERM；随后按独立界面事件让出事件循环的 1000 次启停通过。产品对状态写入失败明确暂停、取消在途轮次并返回原始错误，不自动重试，也不将失败报告为保存成功。

短时测试不证明所有任务都没有泄漏，也不替代连续数天含真实浏览器、视频与模型 SDK 的运行验证。GPU、RSS 与 JavaScript 堆含义不同，不能只用堆稳定宣称整个系统不存在泄漏。

验证命令：

- node scripts/test-long-alive.cjs
- .\\node_modules\\.bin\\electron.cmd scripts/test-long-alive-ui.cjs
- .\\node_modules\\.bin\\electron.cmd scripts/test-ui-performance.cjs
- .\\node_modules\\.bin\\electron.cmd scripts/test-agi-screen-requests.cjs

本轮修改包含主进程与 preload，需要完整退出并重启源码版才加载。仅刷新页面不更新主进程；旧安装包不会自动包含本功能。
