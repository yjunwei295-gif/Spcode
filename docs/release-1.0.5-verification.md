# SimpleCode 1.0.5 发布与验证记录

发布日期：2026-11-17。平台：Windows 10/11 x64。许可证沿用 Apache-2.0。

## 本次发布

- 汇入当前会话恢复、任务续做、图文插话与 Codex 会话生命周期相关源码及测试。
- 完整退出后重新启动，可恢复已保存的打开标签顺序、当前标签与草稿；各窗口分别保存打开清单。
- 兼容的方法与界面资源继续支持空闲热更新。顶层初始化、函数签名和闭包结构变化仍须重启；不把被拒绝的更新当成已经生效。
- 源码仓库不包含本轮构建现场、隔离测试用户目录及本地大体积产物。
